# US-Targeted Keyword Strategy

## Why this phase comes before on-page work

On-page optimization (titles, headers, content) is only as good as the keyword decisions underneath it. Optimizing a page's copy before knowing what it should actually target wastes the work that follows — do this phase first, or revisit it if it wasn't done properly before.

## Step 1 — Map every existing page to keywords

For each page: one **primary keyword** and 2-4 **secondary/long-tail keywords**. Choose them the way a real US searcher would actually phrase the query — not a direct restatement of the page's internal name or the site owner's internal jargon. Useful, honest methods for this without live search-volume data:
- What would a US user actually type into Google for this need? Construct the query the way a person speaks, not the way a product spec is written.
- What does Google's autocomplete plausibly suggest for the head term? (Reason from common query patterns — question words, comparison phrasing "X vs Y," modifiers like "free," "best," "near me" where geographically relevant.)
- What are named competitors (if any were provided) actually targeting on their equivalent page? Fetch their titles, H1s, and URL slugs directly rather than guessing.

**Do not fabricate specific search-volume or difficulty numbers.** If you don't have a live data source, say so plainly and reason from query construction and competitor coverage instead.

## Step 2 — Check for keyword cannibalization

Look for two or more pages effectively targeting the same primary keyword. This splits ranking signal instead of concentrating it. Resolve by either:
- Differentiating the pages' angles/intent clearly enough that they're not actually competing, or
- Consolidating into one stronger page and redirecting the other.

## Step 3 — Identify keyword gaps

If named competitors exist, note real, US-relevant queries in the niche that they cover and this site doesn't. List these as content opportunities — don't silently create new pages for them unless that's explicitly part of the current task's scope.

## Step 4 — Confirm search intent match

For every page, confirm the content type matches the query's actual intent:
- **Informational** ("how does X work," "what is X") → explanatory content, not a sales page.
- **Commercial investigation** ("best X," "X vs Y") → comparison-oriented content.
- **Transactional** ("buy X," "X near me," "sign up for X") → action-oriented, low-friction content.
- **Navigational** (looking for a specific known page/brand) → make sure that exact page is easy to find and ranks for its own name.

A mismatch here is a ranking ceiling — no amount of title/meta/header polish fixes a page answering the wrong kind of question for its target query.

## Deliverable for this phase

A keyword map table:

```
| Page URL | Primary Keyword | Secondary Keywords | Search Intent | Current Match Quality | What Changed |
```

Flag any cannibalization found and how it was resolved, and list any genuine content gaps identified (without necessarily filling them, unless in scope).
